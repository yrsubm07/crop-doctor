# Crop Doctor

AI-Based Crop Disease Detection System — SIH trial project.

## Local prerequisites

Install these before creating the runnable frontend and backend:

1. Node.js LTS (includes npm)
2. Python 3.11 or newer (select **Add python.exe to PATH** during setup)
3. Git
4. VS Code (recommended)

## Verify installation

Open a new PowerShell window in this folder and run:

```powershell
node --version
npm --version
python --version
git --version
```

All four commands must print version numbers before continuing to Step 3.
